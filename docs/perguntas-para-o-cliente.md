# Perguntas para a Proprietária

Este arquivo lista informações pendentes para configurar a automação sem inventar serviços, regras ou promessas comerciais.

## Serviços

- Quais serviços a Alfacred deseja exibir no menu?
- Qual deve ser o nome público de cada serviço?
- Qual descrição curta deve aparecer para cada serviço?
- Qual a ordem das opções?
- Algum serviço deve ficar temporariamente oculto?
- Algum serviço exige atendimento humano antes do formulário?
- Algum serviço exige atendimento humano depois do formulário?

## Formulários

- Será usado um formulário único ou um formulário por serviço?
- Quais são os links oficiais dos formulários?
- Os links são públicos e HTTPS?
- O cliente deve confirmar que preencheu o formulário?
- Existe uma página de política de privacidade para vincular ao formulário?

## Perguntas antes do formulário

- A empresa deseja fazer alguma pergunta antes de enviar o link?
- É necessário pedir nome no WhatsApp ou o nome do perfil é suficiente?
- Alguma pergunta pode envolver dado sensível? Se sim, deve ser movida para formulário seguro.

## Mensagens

- Qual tom de voz a Alfacred deseja usar?
- Qual mensagem de boas-vindas deve ser aprovada?
- Qual texto exato do aviso de privacidade?
- Qual mensagem deve ser enviada quando a opção for inválida?
- Qual mensagem deve ser enviada ao encerrar?
- Existem palavras ou promessas que devem ser evitadas?

## Atendimento humano

- Quem receberá as notificações de atendimento humano?
- Qual canal interno será usado para notificar a funcionária?
- Qual horário de atendimento?
- O que fazer fora do horário?
- Depois que a atendente assumir, quem marca a conversa como `ATENDIMENTO_HUMANO`?
- Quem pode reativar a automação?
- Quando uma conversa deve ser finalizada?

## Regras operacionais

- A automação deve funcionar em feriados?
- Existe fila de atendimento?
- Existe prioridade por tipo de serviço?
- O cliente pode trocar de serviço durante a conversa?
- Após quantos dias sem resposta a conversa pode ser encerrada?

## Privacidade e LGPD

- Qual política de privacidade oficial deve ser informada?
- Qual base legal será adotada para o tratamento?
- Por quanto tempo os registros devem ser mantidos?
- Quem terá acesso ao banco e ao n8n?
- Como será tratado o envio acidental de documentos, CPF ou dados bancários?
